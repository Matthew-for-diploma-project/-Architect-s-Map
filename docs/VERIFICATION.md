## Ограничения проверки

Полная проверка интерфейса в браузере не выполнена: штатный сервис предпросмотра этой среды недоступен (`preview relay unavailable`). Другой сервер предпросмотра для обхода этого ограничения не запускался. Поэтому действия мышью, визуальное совмещение карты и загрузка пользовательских файлов в браузере в этой сессии не подтверждены.

Тесты API используют контролируемые подменённые сетевые ответы. Доступность и актуальность живых НСПД, CoGIS, Nominatim, CDN и картографических подложек из компьютера пользователя не проверялась. Сетевые отказы не устранялись изменением исходного приложения.

Сборка, обработчик Worker, преобразование данных, содержимое экспортируемых файлов и восстановление истории проверены отдельно от этих внешних зависимостей.

## Повторение основных проверок

Из корня проекта:

```bash
node tools/check-integrity.mjs
npm run build
npm test
```

Для браузерной проверки на своём компьютере:

```bash
node tools/serve.mjs
```

Откройте http://127.0.0.1:3000/ и выполните ручной сценарий из README.

Контрольные суммы относятся к исходной итерации 13. После собственных изменений несовпадение с этим исходным снимком ожидаемо.
