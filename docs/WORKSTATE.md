## Окружение и ограничения

Node 24.22.1 / npm 11.9.0, Playwright 1.62.1. Обход Chromium подтверждён: вне репозитория установить `npm install --prefix <qa> @sparticuz/chromium@153.0.0 @embedded-postgres/linux-x64@17.11.0-beta.19`; выполнить пакетный `scripts/hydrate-symlinks.js` PostgreSQL. Задать TMPDIR в доступный для записи каталог до импорта @sparticuz/chromium, получить путь через `await chromium.executablePath()` и передать его как PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH. Headless Shell 153.0.8010.0 работает с обычными launch-опциями существующих тестов, без изменения приложения/зависимостей проекта.

PostgreSQL 17.11: initdb с UTF8, postgres с `-h 127.0.0.1 -k '' -c dynamic_shared_memory_type=mmap`; две отдельные _test БД с обычными ролями для browser/integration. Локально DATABASE_SSL=disable; PUBLIC_ORIGIN совпадает с P13_BASE_URL/P14_BASE_URL (`http://127.0.0.1:3004`). Для browser выполнить миграции и поднять tools/serve.mjs, задать P14_TEST_DATABASE_URL той же БД и AUTH_REGISTER_MAX_ATTEMPTS/AUTH_LOGIN_MAX_ATTEMPTS=1000. Серверы и тесты запускать внутри одной команды: loopback между командами изолирован. Пароли/окружение, QA-пакеты и PNG вне Git; процессы закрывать после прогона. Git push не авторизован; контрольные точки сохраняются через GitHub Git API с проверкой удалённого дерева. Прежнее переполнение свёрнутых панелей остаётся P31.
