## Окружение и ограничения

Работа из корня репозитория; для документационных проверок достаточно Git и Python 3. PostgreSQL, Node-сервер и браузер не запускаются. Секреты и временные QA-данные не нужны. Карточка хранит идентификатор своей точки; содержащий её SHA и состояние доставки читаются из GitHub без коммита ради собственного хеша.
