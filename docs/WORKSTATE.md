## Окружение и ограничения

Node 24.22.1 / npm 11.9.0, PostgreSQL 17.11 из @embedded-postgres/linux-x64@17.11.0-beta.19 (scripts/hydrate-symlinks.js), Playwright 1.62.1. Подготовлена новая QA-область вне репозитория. Полный /usr/bin/chromium падает на process_singleton_posix: socket() Operation not permitted. npx playwright install --only-shell chromium получает повреждённый ZIP; следующая альтернатива — поставка Headless Shell через npm @sparticuz/chromium. Все серверы и браузерные тесты запускать внутри одной команды: loopback между командами изолирован, как и в прежних попытках. PUBLIC_ORIGIN совпадает с браузерным URL; отдельные обычные роли/UTF8 _test БД для browser/integration. Секреты и QA-зависимости не входят в Git. Git push не авторизован; контрольные точки сохраняются через GitHub Git API, затем подтверждаются чтением. Прежнее переполнение свёрнутых панелей остаётся P31.
